# Go

> Принципы использования Go. Общие инженерные принципы — в [SKILL.md](../SKILL.md), здесь только специфика языка и стека.

## Инструменты

- **CLI: `github.com/spf13/cobra` с первой команды.** Не начинать CLI-приложение на `flag` с расчётом мигрировать позже: сразу использовать Cobra, чтобы без смены интерфейса добавлять subcommands, общие flags, help и completion.

## Принципы

- Держать `main()` минимальным: создать root command, выполнить через `ExecuteContext`, обработать ошибку и exit code.
- Runtime-логику возвращать через `RunE` и обычные функции с `error`; не вызывать `os.Exit` внутри бизнес-логики.
- Передавать cancellation через `context.Context` от Cobra command до listener, сетевых запросов и фоновых goroutine.
- Не создавать пустые subcommands и CLI scaffolding «на будущее»: Cobra нужна как стабильная точка расширения, команды добавляются по фактической необходимости.

## Анти-паттерны

- Стандартный `flag` для нового CLI-приложения вместо Cobra.
- `os.Exit` или `log.Fatal` глубже `main()`.
- Глобальные mutable flags вместо значений, замкнутых в конструкторе command.
